# AfrizZenith Design System

## Purpose

This document defines the visual rules for the AfrizZenith website.

The goal is consistency across pages without making every section look identical.

## Brand Direction

AfrizZenith should feel:

-   Premium
-   Professional
-   Modern
-   Confident
-   Human
-   Technology-focused
-   Business-oriented
-   African in context, not through stereotypes

The visual language should balance dark premium sections with clean
light content sections.

## Color

Use centralized design tokens.

The primary brand direction is:

-   Deep black / near-black for dark sections
-   White and warm off-white for light sections
-   AfrizZenith gold as the primary accent
-   Neutral grays for secondary text and borders

Do not introduce additional accent colors without a design reason.

Gold should be used intentionally for:

-   Primary CTAs
-   Active navigation
-   Small labels
-   Icons
-   Highlights
-   Decorative rules

Do not make the entire interface gold.

## Typography

Typography should have a clear hierarchy:

1.  Page/hero heading
2.  Section heading
3.  Subheading
4.  Body
5.  Supporting text
6.  Small labels

Headings should be strong and concise.

Body text should prioritize readability over stylistic effects.

Avoid excessive font weights.

## Spacing

Use an 8px spacing system wherever practical.

Prefer consistent spacing tokens over arbitrary values.

Major sections should have generous but controlled vertical spacing.

Do not use large empty gaps simply to make a page feel premium.

## Layout

Use a centered content container.

The design should generally follow:

-   Full-width section
-   Centered inner container
-   Consistent horizontal padding
-   Clear alignment between headings, content and imagery

Avoid arbitrary left/right offsets.

## Cards

Cards should be used when they help group related information.

Default card characteristics:

-   Subtle border
-   Controlled radius
-   Minimal shadow
-   Consistent padding
-   Clear hierarchy

Do not put every piece of content inside a card.

## Buttons

Primary buttons should be visually prominent.

The primary button should generally use the brand gold accent.

Secondary buttons may use:

-   Dark background
-   Transparent background
-   Border
-   Text-only treatment

Buttons should have:

-   Clear label
-   Appropriate icon where useful
-   Hover state
-   Focus state
-   Disabled state where applicable

Do not create unnecessary button variants.

## Icons

Use Lucide React or React Icons.

Icons should support meaning rather than decoration.

Maintain consistent stroke/weight and sizing within a section.

## Borders

Use borders sparingly.

Borders should define structure, not decorate every element.

Prefer subtle neutral borders.

## Shadows

Use restrained shadows.

Avoid:

-   Strong floating-card shadows
-   Multiple shadow layers
-   Glow effects
-   Excessive depth

The website should feel clean rather than overly glossy.

## Images

Photography should feel authentic and professional.

Prefer imagery that shows:

-   People collaborating
-   Real business environments
-   Technology in use
-   African business contexts
-   Professional teams

Avoid generic "AI technology" imagery with robots, holograms or glowing
brains.

## Section Rhythm

Sections should alternate naturally.

For example:

-   Dark hero
-   Light story section
-   Soft neutral values section
-   Light process section
-   Dark CTA/footer

Do not force every section into the same visual template.

## Responsive Principles

On mobile:

-   Reduce heading size without destroying hierarchy.
-   Reduce horizontal padding.
-   Stack content when necessary.
-   Maintain meaningful image prominence.
-   Keep CTA buttons easy to tap.
-   Preserve visual rhythm.

On tablet:

-   Avoid awkward half-desktop layouts.
-   Use two-column layouts when content supports them.
-   Adjust spacing rather than simply shrinking everything.

On desktop:

-   Take advantage of whitespace.
-   Maintain readable line lengths.
-   Avoid excessively wide text blocks.
-   Use imagery to balance content.

## Visual Restraint

When unsure whether to add a visual effect, do not add it.

Strong typography, composition, spacing and imagery should carry the design.
